# NATIVE Website V1

Multilingual Next.js prototype for NATIVE — DE / EN / ZH.

## Run
1. `npm install`
2. `npm run dev`
3. Open `http://localhost:3000`

## Routes
- `/de`, `/en`, `/zh`
- `/{locale}/creators`
- `/{locale}/brands`
- `/{locale}/services`
- `/{locale}/about`
- `/{locale}/contact`
